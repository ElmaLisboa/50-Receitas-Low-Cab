ロカボキッチンへようこそ

これは単なるダイエット本ではありません。食生活を続けるうえで必ず出てくる質問、「今日は何を作ろう？」への50の答えです。

ロカボは、寂しいサラダだけを食べることではありません。満足感のあるオムレツ、切り分けられるラザニア、日曜日のフェイジョアーダ、そしてチーズケーキまで。小麦粉や砂糖を、満足感のある材料に置き換えて楽しみます。

本書の基本ルール：炭水化物は主役ではなくアクセント。味と色を加え、主役はたんぱく質、良質な脂質、野菜です。

7週間、毎日一つ新しいレシピを作れば、忙しい月曜日も乗り切れるレパートリーが身につきます。召し上がれ。

本書の使い方

1. 最後から始める。買い物前に「7日間メニュー」と買い物リストを確認しましょう。

2. ちょうどよく多めに作る。昼食と夕食の多くは2人分。残りは翌日の昼食になります。

3. ボックスを活用する。各レシピに料理のコツと代替案があります。

4. 炭水化物ゼロを目指さない。栄養成分は選択を助けるためのものです。

5. 冷凍を活用する。冷凍の説明があるレシピは1人分で保存できます。

第01章

朝食と簡単スナック

いつものパンに頼らず、手軽で満足感のあるレシピで一日を始めましょう。卵、チーズ、アーモンド粉やココナッツ粉、果物をバランスよく使います。ほとんどが実際の作業時間15分以内です。

01

ほうれん草とチーズのオーブンオムレツ

調理時間 10分合計 30分分量 2難易度 簡単
385kcal / 1人分6 g炭水化物27 gたんぱく質28 g脂質

材料

  • 卵4個
  • カップ1 ほうれん草 （みじん切り） (新鮮な または 冷凍, （水気をしぼった）)
  • 50g モッツァレラチーズ （すりおろし）
  • 大さじ2 生クリーム
  • 玉ねぎ1/2個 （みじん切り）
  • 大さじ1 オリーブオイル
  • 塩, 黒こしょう、ナツメグ 適量

作り方

  1. 玉ねぎをオリーブオイルで3分炒め、ほうれん草を加えて水分がなくなるまで加熱します。
  2. 卵、生クリーム、塩、こしょう、ナツメグを混ぜます。
  3. 炒めた具とチーズを卵液に混ぜ込みます。
  4. 油を塗った小さな耐熱皿に流し入れ、180℃で20〜25分、中心が固まるまで焼きます。
料理のコツ： 一度に2個作ると便利です。1個は冷蔵庫で3日保存でき、翌朝の朝食になります。
↺ 代替アイデア： ほうれん草は、すりおろして水気をしぼったズッキーニに替えられます。味がより淡白になります。

2分で作れるロカボ電子レンジパン

調理時間 5分合計 7分分量 1難易度 簡単
245kcal / 1人分4 g炭水化物14 gたんぱく質18 g脂質

材料

  • 卵1個
  • 大さじ2 アーモンドプードル
  • 大さじ1 生クリーム
  • 小さじ1/2 ベーキングパウダー
  • 1 ひとつまみ の 塩
  • 小さじ1/2 バター （型に塗る用）

作り方

  1. 材料をすべて油を塗ったマグカップまたは四角い容器に入れ、フォークで粉のダマがなくなるまで混ぜます。
  2. 電子レンジの高出力で90秒加熱します。
  3. 型から外して半分に切り、フライパンまたはトースターで片面1分ずつ焼き色をつけます。
料理のコツ： 電子レンジの後に焼き色をつけるのがポイントです。電子レンジだけではパンの色と食感が出ません。
↺ 代替アイデア： アーモンドプードルがない場合は、金色の亜麻仁粉大さじ1とココナッツフラワー大さじ1で代用します。

バナナとオートミールのパンケーキ（小麦粉なし）

調理時間 8分合計 15分分量 2難易度 簡単
260kcal / 1人分22 g炭水化物15 gたんぱく質12 g脂質

材料

  • バナナ1個 しっかり 熟した
  • 卵2個
  • 大さじ3 ふすま の オートミール
  • 小さじ1/2 シナモン
  • 小さじ1/2 ベーキングパウダー
  • 小さじ1 バター または ココナッツオイル

作り方

  1. バナナをフォークでなめらかなピューレになるまでつぶします。
  2. 卵、オートミール、シナモン、ベーキングパウダーを加え、よく混ぜます。
  3. バターを弱火で温め、生地を少量ずつ流し入れます。
  4. 片面2分ずつ焼き、表面に気泡が出たら裏返します。
料理のコツ： 皮に茶色い斑点が出るほど熟したバナナを使うと、砂糖なしでも自然な甘さになります。
↺ 代替アイデア： バナナをすりおろしたりんご1/2個と甘味料小さじ1に替えると、糖質をさらに抑えられます。

卵・野菜・ベーコンの塩味マフィン

調理時間 15分合計 35分分量 6難易度 簡単
180kcal / 1人分3 g炭水化物12 gたんぱく質13 g脂質

材料

  • 卵6個
  • カップ1/2 ベーコン 角切り
  • 1/2 ズッキーニ （すりおろし）、（水気をしぼった）
  • カップ1/2 チーズ （すりおろし）
  • 大さじ2 青ねぎ （みじん切り）
  • 塩、こしょう 適量

作り方

  1. ベーコンを焼き色がつくまで炒め、キッチンペーパーで油を切ります。
  2. ズッキーニをすりおろして塩を振り、5分置いてから手でしっかり水気をしぼります。
  3. 卵を溶き、すべての材料を混ぜてマフィン型に分け入れます。
  4. 180℃で20〜25分、中心が固まるまで焼きます。
料理のコツ： ジッパー付き袋で冷凍し、電子レンジで30秒温めれば、30秒で朝食を用意できます。
↺ 代替アイデア： ベーコンをほぐし鶏肉に替えると、飽和脂肪酸を減らせます。

チーズとトマトのタピオカクレープ

調理時間 5分合計 10分分量 1難易度 簡単
290kcal / 1人分14 g炭水化物18 gたんぱく質16 g脂質

材料

  • 卵1個
  • 大さじ1 すり切り の タピオカ粉
  • 大さじ1 クリームチーズ または 生クリーム
  • 2 薄切り の モッツァレラチーズ
  • 3 輪切り 細い の トマト
  • オレガノ、塩 適量

作り方

  1. 卵、タピオカ粉、クリームチーズ、塩を均一になるまで混ぜます。
  2. こびりつかないフライパンを弱火で温め、生地を流し入れます。
  3. 2分焼いて裏返し、チーズとトマトをのせて半分に折ります。
  4. ふたをしてさらに1分、チーズが溶けるまで加熱します。
料理のコツ： 弱火が成功のコツです。強火にすると乾いて、折るときに割れやすくなります。
↺ 代替アイデア： 甘いアレンジなら、ピーナッツバター小さじ1とシナモンを詰めます。

フライパンで作るチーズパン

調理時間 5分合計 10分分量 1難易度 簡単
275kcal / 1人分6 g炭水化物16 gたんぱく質21 g脂質

材料

  • 卵1個
  • 大さじ2 サワーキャッサバスターチ
  • 大さじ2 パルメザンチーズ または モッツァレラ （すりおろし）
  • 大さじ1 生クリーム
  • 1 ひとつまみ の 塩

作り方

  1. 材料をすべてフォークで、クリーミーな生地になるまで混ぜます。

  3. ふたをして4分焼き、裏返してさらに3分焼きます。
  4. 半分に切り、熱いうちに具を詰めます。
料理のコツ： 甘いキャッサバ粉ではなく酸味のあるタイプを使うと、特徴的なもちもち感が出ます。
↺ 代替アイデア： 具には、オレガノ入りクリームチーズ、またはほぐし鶏肉とカトゥピリが合います。

クリーミーチキンのコラードラップ

調理時間 12分合計 20分分量 2難易度 簡単
310kcal / 1人分9 g炭水化物26 gたんぱく質19 g脂質

材料

  • 4 葉 大きい の コラードグリーン
  • カップ1 鶏肉 ゆでた ほぐした
  • 大さじ3 クリームチーズ または ヨーグルト プレーン
  • 1/2 にんじん （すりおろし）
  • カップ1/2 レタス （みじん切り）
  • 果汁 の 1/4 の レモン, 塩、こしょう

作り方

  1. ケールの葉を沸騰した湯に20秒通し、すぐ冷水に取ります。加熱しすぎず、葉を柔らかくする方法です。
  2. 鶏肉、クリームチーズ、レモン汁、塩、こしょうを混ぜます。
  3. 水気をふいた葉に、レタス、にんじん、クリーミーな鶏肉をのせます。
  4. 両端を折り込みながらしっかり巻き、半分に切ります。
料理のコツ： ケールの葉はキッチンペーパーでよくふいてください。濡れていると手の中でラップが崩れます。
↺ 代替アイデア： ケールを生のスイスチャードに替えると、より歯ごたえが出ます。湯通しも不要です。

アボカドと種のクリーミースクランブルエッグ

調理時間 8分合計 10分分量 1難易度 簡単
405kcal / 1人分8 g炭水化物20 gたんぱく質33 g脂質

材料

  • 卵2個
  • 大さじ1 バター
  • アボカド1/2個 小さい 薄切り
  • 大さじ1 ひまわりの種 または かぼちゃ
  • 青ねぎ （みじん切り）, 塩、こしょう

作り方

  1. 卵を塩、こしょうと混ぜます。泡立てないようにします。
  2. バターを弱火で溶かし、卵を流し入れて20秒、混ぜずに待ちます。
  3. ヘラで中心から縁へ卵を寄せ、クリーミーで少し水分が残るまで繰り返します。
  4. すぐに盛り付け、アボカド、種、青ねぎをのせます。
料理のコツ： まだ生っぽく見える段階で火を止めます。フライパンの余熱で火が通ります。
↺ 代替アイデア： アボカドの代わりに、レモンを加えたサワークリーム大さじ2を使えます。

プロテインヨーグルトとナッツグラノーラ

シンプルなカリフラワーライス

調理時間 10分合計 15分分量 4難易度 簡単
65kcal / 1人分5 g炭水化物4 gたんぱく質3 g脂質

材料

  • 1 カリフラワー 中くらい で 小房
  • 大さじ1 オリーブオイル
  • にんにく2片 （みじん切り）
  • 1/4 の 玉ねぎ （みじん切り）
  • 塩、刻みハーブ

作り方

  1. 生のカリフラワーを短く数回フードプロセッサーにかけ、ごはん粒ほどの大きさにします。粗いおろし金でも構いません。
  2. にんにくと玉ねぎをオリーブオイルで2分炒めます。
  3. カリフラワーを加え、強火で5〜6分、混ぜながら炒めます。
  4. 塩で味を調え、刻みハーブを加えます。ふたをするとピューレになるので、ふたはしません。
料理のコツ： カリフラワーは必ず生のまま、短いパルスで処理します。ゆでたものを使うと水が出てペースト状になります。
↺ 代替アイデア： 淡白なベースなので、冷蔵庫で4日保存でき、残ったたんぱく質をのせて使えます。

ズッキーニ麺の自家製トマトソース

調理時間 12分合計 30分分量 2難易度 簡単
265kcal / 1人分14 g炭水化物12 gたんぱく質18 g脂質

材料

  • 2 ズッキーニ 大きい
  • トマト6個 熟した (または 1 缶 の ホールトマト)
  • にんにく2片
  • 玉ねぎ1/2個
  • 大さじ1 オリーブオイル
  • バジル, 塩、こしょう
  • パルメザン （すりおろし） 仕上げ用

作り方

  1. ソースを作ります。玉ねぎとにんにくを炒め、刻んだトマトを加えて弱火で20分、とろみがつくまで煮ます。
